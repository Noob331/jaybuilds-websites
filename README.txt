JAYBUILDS.IN — FRESH WEBSITE REDESIGN
====================================

PREVIEW
1. Extract the entire ZIP first.
2. Open the JAYBUILDS-IN folder.
3. Double-click index.html.
4. Keep all HTML files and the assets folder together.

PAGES
Home, Services, Our Work, Pricing, About, Blog, FAQ, Contact, Privacy Policy, Terms, and 404.

ASSETS
- assets/style.css: complete responsive visual design
- assets/app.js: mobile menu, reveal animations, WhatsApp links, enquiry form handling
- assets/hero-studio.webp: original generated colourful 3D website-launch illustration

IMPORTANT
- Portfolio examples are labelled demo concepts.
- Pricing is proposed starting pricing; confirm a written project scope.
- Contact form opens WhatsApp with the enquiry details; it does not store data on a server.
- Privacy policy and terms are draft templates; review and adapt before launch.
- Admin dashboard, database, payment gateway and customer login are not included in this public-site version.
- Website URLs and sitemap are configured for https://jaybuilds.in; actual domain availability/DNS and HTTPS must be configured with your host.
- Google Fonts is loaded from an online stylesheet; a system sans-serif fallback is provided.
